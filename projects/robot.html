Arduino Tank Robot

A hardware and software build using Arduino and servos to create a tank-style robot with scripted movement.

Overview

I built a small tank robot (nicknamed "Turny") that uses servo motors for movement and an Arduino for control logic. The goal was to create reliable, repeatable motion sequences and test basic interaction patterns.

What I did

  • Wired and configured servo motors and controls, including button-triggered sequences
  • Wrote Arduino code to run consistent movement patterns and timing
  • Debugged and tuned inputs, delays, and movement for reliability

Outcome

This project improved my comfort with hardware debugging and reinforced how to translate an idea into a testable system.

Built with
Arduino, servo motors
